## 2. Périmètre de la mission

**Inclus dans le prix one-shot :**

- Analyse et cartographie de vos flux de demandes entrants (1 jour)
- Configuration du workflow n8n de capture et qualification (Gmail + formulaire Tally)
- Intégration OpenAI gpt-4o-mini pour extraction automatique : type projet, surface, budget, zone, urgence
- Scoring automatique Chaud / Tiède / Froid avec règles métier BTP
- Création de la base CRM Airtable (tableau de bord leads)
- Envoi automatique d'emails de réponse personnalisés (via Resend)
- Alertes téléphone en temps réel pour les leads Chauds
- Digest hebdomadaire récapitulatif (email lundi 8 h)
- Documentation utilisateur (guide 5 pages)
- Formation de votre référent interne (2 h à distance)
- Support recette + 30 jours post-livraison

**Exclus du périmètre :**

- Reprise des leads historiques (import données passées = option sur devis)
- Intégration à un logiciel métier BTP existant (Batigest, Onaya…) = option sur devis
- Développement d'une application mobile dédiée
- Création du formulaire web (fourni prêt à l'emploi via Tally, gratuit)
